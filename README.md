# Temperature Converter (UDF Flutter Lab)

Android app that converts temperatures between Celsius, Fahrenheit and Kelvin, built with Flutter to demonstrate User Defined Functions.

**Team:** A. Anirudh (247R1A6603), D. Srikar Reddy (247R1A6621), G. Prashanth (247R1A6622) — CMR Technical Campus

## Install on an Android phone
1. Download `TemperatureConverter.apk` from this repo (click the file, then **Download raw file**).
2. Open it from the phone's **Files** / **Downloads**.
3. If prompted, allow **Install unknown apps** for that app, then tap **Install**.
4. If Play Protect warns, tap **More details → Install anyway**.

Requires Android 7.0 or newer.
